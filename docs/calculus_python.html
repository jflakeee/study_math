1미분: 순간 기울기

미분은 함수가 한 지점에서 얼마나 빠르게 변하는지, 즉 그 지점의 기울기를 구하는 일입니다. 기울기가 0인 곳은 최댓값이나 최솟값 후보가 되기 때문에, 손실 함수를 줄여 나가는 경사 하강법이 바로 이 성질을 이용합니다.

두 점으로 기울기 근사하기

곡선 위의 두 점을 잡고 그 사이 직선의 기울기를 구한 뒤, 두 점의 간격을 점점 좁히면 순간 기울기에 가까워집니다.

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

\(f(x)=x^2\)에서 \(x=2\)와 \(x=2.1\)을 잇는 직선의 기울기는 \(\frac{4.41-4}{0.1}=4.1\)입니다. 간격을 0.00001까지 좁히면 4에 매우 가까워집니다.

def derivative_approx(f, x, step=1e-5):
    return (f(x + step) - f(x)) / step

print(derivative_approx(lambda v: v ** 2, 2))
# 4.000010000027032

SymPy로 정확한 도함수 구하기

diff()로 도함수를 구하고 subs()로 원하는 x 값을 대입합니다.

from sympy import symbols, diff

x = symbols('x')
f = x ** 2
dx_f = diff(f, x)
print(dx_f)              # 2*x
print(dx_f.subs(x, 2))   # 4

2편도함수

변수가 여러 개인 함수에서는 한 변수에 대해서만 미분하고 나머지 변수는 상수로 취급합니다. 이것을 편미분이라 하고, 결과를 편도함수라고 합니다.

$$f(x, y) = 2x^3 + 3y^3$$ $$\frac{\partial f}{\partial x} = 6x^2, \qquad \frac{\partial f}{\partial y} = 9y^2$$

점 \((1, 2)\)에서 x 방향 기울기는 \(6\), y 방향 기울기는 \(36\)입니다. 이 두 값을 모은 벡터 \((6, 36)\)이 기울기 벡터(gradient)이며, 경사 하강법은 이 벡터의 반대 방향으로 이동합니다.

from sympy import symbols, diff

x, y = symbols('x y')
f = 2 * x ** 3 + 3 * y ** 3
dfdx = diff(f, x)   # 6*x**2
dfdy = diff(f, y)   # 9*y**2
print(dfdx.subs({x: 1, y: 2}), dfdy.subs({x: 1, y: 2}))
# 6 36

3연쇄 법칙

함수 안에 함수가 들어 있는 합성함수는 바깥 함수의 도함수와 안쪽 함수의 도함수를 곱해서 미분합니다.

$$y = x^2 + 1, \qquad z = y^3 - 2$$ $$\frac{dz}{dx} = \frac{dz}{dy} \cdot \frac{dy}{dx} = 3y^2 \cdot 2x = 6x\,(x^2+1)^2$$

예를 들어 \(x=1\)이면 \(6 \cdot 1 \cdot 2^2 = 24\)입니다. 신경망의 역전파는 출력층부터 입력층까지 층마다의 기울기를 이렇게 곱해 나가는 과정입니다.

from sympy import symbols, diff

x = symbols('x')
y = x ** 2 + 1
z = y ** 3 - 2
dz_dx = diff(z, x)
print(dz_dx)             # 6*x*(x**2 + 1)**2
print(dz_dx.subs(x, 1))  # 24

4적분: 곡선 아래의 넓이

적분은 곡선과 x축 사이의 넓이를 구하는 일이며, 미분의 역연산입니다. 확률 분포에서 특정 구간의 확률을 구할 때도 적분이 쓰입니다.

도형으로 확인하기

\(f(x)=2x\)를 0부터 1까지 적분하면 밑변 1, 높이 2인 삼각형의 넓이와 같습니다.

$$\int_0^1 2x\,dx = \frac{1 \times 2}{2} = 1$$

직사각형으로 근사하기

곡선이 직선이 아니면 구간을 잘게 나눠 직사각형 넓이를 더해 근사합니다. 아래 그림은 \(f(x)=x^2+1\)의 0~1 구간을 직사각형 5개로 나눈 모습이며, 각 직사각형의 높이는 칸 가운데 지점의 함숫값입니다.

def approximate_integral(f, a, b, n):
    width = (b - a) / n
    return sum(f(a + width * (i + 0.5)) * width for i in range(n))

for n in (5, 1000, 1_000_000):
    print(n, approximate_integral(lambda v: v ** 2 + 1, 0, 1, n))

SymPy로 정확한 값 구하기

$$\int_0^1 (x^2 + 1)\,dx = \left[\frac{x^3}{3} + x\right]_0^1 = \frac{4}{3}$$ 
from sympy import symbols, integrate

x = symbols('x')
print(integrate(x ** 2 + 1, (x, 0, 1)))   # 4/3
