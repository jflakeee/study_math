1미분: \(y=x^2\)의 \(x=2\)에서 기울기

곡선 위 한 점의 기울기는 바로 구할 수 없어서, 옆에 점을 하나 더 찍고 두 점 사이 기울기를 구한 뒤 옆 점을 점점 가까이 가져가요. 두 점 사이 기울기 공식은 이거예요.

$$\text{기울기} = \frac{(\text{옆 점의 } y) - (\text{원래 점의 } y)}{(\text{옆 점의 } x) - (\text{원래 점의 } x)}$$

1단계원래 점의 좌표 구하기

\(y = x^2\)주어진 함수
\(y = 2^2\)x 자리에 2를 대입
\(y = 2 \times 2\): 2를 2번 곱함
\(y = 4\)그래서 원래 점은 \((2, 4)\)

2단계옆 점을 \(x=3\)에 찍기 (거리 \(h=1\))

\(y = 3^2 = 3 \times 3 = 9\)x 자리에 3을 대입 → 옆 점 \((3, 9)\)
\(\displaystyle \text{기울기} = \frac{9 - 4}{3 - 2}\)공식에 옆 점 \((3,9)\), 원래 점 \((2,4)\) 대입
\(\displaystyle = \frac{5}{1}\)위: \(9-4=5\), 아래: \(3-2=1\)
\(= 5\)1로 나누면 그대로

3단계옆 점을 \(x=2.1\)에 찍기 (거리 \(h=0.1\))

\(y = 2.1^2 = 2.1 \times 2.1\)x 자리에 2.1을 대입
\(21 \times 21 = 441\): 소수점을 떼고 곱함
\(y = 4.41\)소수점 아래 1+1=2자리 → 옆 점 \((2.1, 4.41)\)
\(\displaystyle \text{기울기} = \frac{4.41 - 4}{2.1 - 2}\)공식에 대입
\(\displaystyle = \frac{0.41}{0.1}\)위: \(4.41-4=0.41\), 아래: \(2.1-2=0.1\)
\(= 4.1\): 소수점을 오른쪽으로 1칸

4단계옆 점을 \(x=2.01\)에 찍기 (거리 \(h=0.01\))

\(y = 2.01^2 = 2.01 \times 2.01\)x 자리에 2.01을 대입
\(201 \times 201 = 40401\)\(201 \times 200 = 40200\), 여기에 \(201\)을 더함
\(y = 4.0401\)소수점 아래 2+2=4자리
\(\displaystyle \text{기울기} = \frac{4.0401 - 4}{2.01 - 2}\)공식에 대입
\(\displaystyle = \frac{0.0401}{0.01}\)위: \(4.0401 - 4 = 0.0401\), 아래: \(2.01 - 2 = 0.01\)
\(= 4.01\): 소수점을 오른쪽으로 2칸

5단계옆 점을 \(x=2.001\)에 찍기 (거리 \(h=0.001\))

\(y = 2.001 \times 2.001\)x 자리에 2.001을 대입
\(2001 \times 2001 = 4004001\)\(2001 \times 2000 = 4002000\), 여기에 \(2001\)을 더함
\(y = 4.004001\)소수점 아래 3+3=6자리
\(\displaystyle \text{기울기} = \frac{4.004001 - 4}{2.001 - 2}\)공식에 대입
\(\displaystyle = \frac{0.004001}{0.001}\)위: \(4.004001 - 4 = 0.004001\), 아래: \(2.001 - 2 = 0.001\)
\(= 4.001\): 소수점을 오른쪽으로 3칸

2미분 규칙이 나오는 과정

이번엔 2 대신 어떤 수든 될 수 있는 \(x\)를 그대로 두고 계산해서, 모든 점에서 통하는 기울기 공식(도함수)을 만들어요.

기호 읽는 법: \((x^2)'\)처럼 괄호 오른쪽 위에 작은 따옴표(프라임)를 붙이면 "괄호 안의 식을 미분한 것", 즉 "괄호 안 식의 기울기 공식"이라는 뜻이에요. \((x^2)' = 2x\)는 "\(x^2\)을 미분하면 \(2x\)"라고 읽어요.

규칙 1\(x^2\)을 미분하면 \(2x\)

\((x+h)^2 = (x+h)(x+h)\)옆 점의 y
\(= x \cdot x + x \cdot h\): 분배법칙, 앞 괄호의 x를 곱함
\(\quad + h \cdot x + h \cdot h\)앞 괄호의 h를 곱함 (윗줄에 이어짐)
\(= x^2 + 2xh + h^2\)\(xh + hx = 2xh\)
\((x+h)^2 - x^2 = 2xh + h^2\)y의 증가량: \(x^2 - x^2 = 0\)
\(\displaystyle \frac{2xh + h^2}{h} = 2x + h\)x의 증가량 h로 나눔
\((x^2)' = 2x\)h를 0에 가깝게 하면 h가 사라짐

검산: \(x = 2\)를 대입하면 \(2 \times 2 = 4\). 과 같아요.

규칙 2\(x^3\)을 미분하면 \(3x^2\)

\((x+h)^3 = (x+h)^2 (x+h)\)3번 곱한 것 = 2번 곱한 것 × 1번 더
\(= (x^2 + 2xh + h^2)(x + h)\)에서 구한 \((x+h)^2\)
\(x^2 \times (x + h) = x^3 + x^2h\): 앞 괄호의 첫째 항
\(2xh \times (x + h) = 2x^2h + 2xh^2\)둘째 항
\(h^2 \times (x + h) = xh^2 + h^3\)셋째 항
\(x^2h + 2x^2h = 3x^2h\)같은 모양끼리 모음
\(2xh^2 + xh^2 = 3xh^2\)같은 모양끼리 모음
\((x+h)^3\)위 결과를 모두 더하면
\(= x^3 + 3x^2h + 3xh^2 + h^3\)같은 모양끼리 모은 결과 사용
\((x+h)^3 - x^3\)y의 증가량
\(= 3x^2h + 3xh^2 + h^3\)\(x^3 - x^3 = 0\)
\(\displaystyle \frac{3x^2h + 3xh^2 + h^3}{h}\)x의 증가량 h로 나눔
\(= 3x^2 + 3xh + h^2\)각 항에서 h를 하나씩 지움: \(3x^2h \div h = 3x^2\), \(3xh^2 \div h = 3xh\), \(h^3 \div h = h^2\)
\((x^3)' = 3x^2\)h를 0에 가깝게 하면 \(3xh\)와 \(h^2\)이 사라짐

규칙 3앞에 곱한 숫자는 그대로 따라 나온다

\(2x^3\)의 증가량은 \(x^3\)의 증가량의 2배모든 y 값이 2배라서 증가량도 2배
\((2x^3)' = 2 \times 3x^2 = 6x^2\)에 2를 곱함

규칙 4숫자만 있는 항을 미분하면 0

\(y = 5\)x가 무엇이든 y는 항상 5
\(\displaystyle \frac{5 - 5}{h} = \frac{0}{h} = 0\)y의 증가량이 0
\((5)' = 0\)수평선은 기울기 0

규칙 5더해진 식은 각각 미분해서 더한다

\((x^2 + 1)' = (x^2)' + (1)'\)증가량도 각각 더해지기 때문
\(= 2x + 0 = 2x\)과

3편미분: \(f(x,y)=2x^3+3y^3\)의 점 \((1,2)\)

변수가 x, y 두 개예요. 한 방향으로만 움직인다고 생각하고, 움직이지 않는 변수는 숫자로 바꿔서 미분해요.

기호 읽는 법: \(\dfrac{\partial f}{\partial x}\)는 "f를 x에 대해서만 미분한 것(x 방향 기울기)"이라는 뜻이에요. \(\partial\)는 "라운드" 또는 "델"이라고 읽고, 분수처럼 생겼지만 나눗셈이 아니라 하나의 기호예요.

x 방향y = 2로 고정하고 x로 미분

\(f = 2x^3 + 3y^3\)주어진 함수
\(f = 2x^3 + 3 \times 2^3\)움직이지 않는 y 자리에 2를 대입
\(2^3 = 2 \times 2 \times 2 = 8\)
\(f = 2x^3 + 3 \times 8 = 2x^3 + 24\)\(3 \times 8 = 24\)
\(\displaystyle \frac{\partial f}{\partial x} = (2x^3)' + (24)'\): 각각 미분
\(= 6x^2 + 0 = 6x^2\)과
\(= 6 \times 1^2\)x 자리에 1을 대입
\(= 6 \times 1\)\(1^2 = 1 \times 1 = 1\)
\(= 6\)

y 방향x = 1로 고정하고 y로 미분

\(f = 2 \times 1^3 + 3y^3\)움직이지 않는 x 자리에 1을 대입
\(1^3 = 1 \times 1 \times 1 = 1\)
\(f = 2 \times 1 + 3y^3 = 2 + 3y^3\)\(2 \times 1 = 2\)
\(\displaystyle \frac{\partial f}{\partial y} = (2)' + (3y^3)'\): 각각 미분
\(= 0 + 3 \times 3y^2 = 9y^2\), 그리고 (x 대신 y)
\(= 9 \times 2^2\)y 자리에 2를 대입
\(= 9 \times 4\)\(2^2 = 2 \times 2 = 4\)
\(= 36\)

5단계미분해서 \(x^2 + 1\)이 되는 식 \(F(x)\) 찾기

\((x^3)' = 3x^2\): \(x^3\)을 미분하면 3이 하나 더 붙음
\(\displaystyle \left(\frac{x^3}{3}\right)' = \frac{3x^2}{3} = x^2\)미리 3으로 나눠 두면 붙은 3이 지워짐
\((x)' = 1\)직선 \(y = x\)의 기울기는 1
\(\displaystyle F(x) = \frac{x^3}{3} + x\): 둘을 더하면 미분 결과는 \(x^2 + 1\)

6단계끝값 1과 시작값 0을 대입해서 빼기

\(\displaystyle F(1) = \frac{1^3}{3} + 1\)x 자리에 1을 대입
\(\displaystyle = \frac{1}{3} + 1\)\(1^3 = 1 \times 1 \times 1 = 1\)
\(\displaystyle = \frac{1}{3} + \frac{3}{3} = \frac{4}{3}\): 분모 맞추기
\(\displaystyle F(0) = \frac{0^3}{3} + 0 = \frac{0}{3} + 0 = 0\)x 자리에 0을 대입, 0을 3으로 나누면 0
\(\displaystyle F(1) - F(0) = \frac{4}{3} - 0 = \frac{4}{3}\)끝값에서 시작값을 뺌
\(4 \div 3 = 1.3333\cdots\)직사각형으로 어림한 값과 같음 ✓

먼저 풀어 본 뒤 눌러서 한 줄씩 비교해 보세요.

문제 1. \(y = x^2\)에서 \(x = 3\)일 때 기울기는?
\((x^2)' = 2x\)
\(= 2 \times 3\)x 자리에 3을 대입
\(= 6\)
문제 2. \(f(x, y) = x^2 + y^2\)의 점 \((3, 4)\)에서 x 방향, y 방향 기울기는?
\(f = x^2 + 4^2 = x^2 + 16\)x 방향: y 자리에 4 대입, \(4 \times 4 = 16\)
\(\displaystyle \frac{\partial f}{\partial x} = 2x + 0 = 2x\)
\(= 2 \times 3 = 6\)x 자리에 3 대입
\(f = 3^2 + y^2 = 9 + y^2\)y 방향: x 자리에 3 대입, \(3 \times 3 = 9\)
\(\displaystyle \frac{\partial f}{\partial y} = 0 + 2y = 2y\)
\(= 2 \times 4 = 8\)y 자리에 4 대입
문제 3. \(y = x + 1\), \(z = y^2\)일 때 \(x = 2\)에서 z의 기울기는?
\(y = 2 + 1 = 3\)x 자리에 2 대입
\(\displaystyle \frac{dy}{dx} = (x)' + (1)' = 1 + 0 = 1\)첫째 고리
\(\displaystyle \frac{dz}{dy} = (y^2)' = 2y = 2 \times 3 = 6\)둘째 고리, y 자리에 3 대입
\(\displaystyle \frac{dz}{dx} = 6 \times 1 = 6\)두 고리를 곱함
문제 4. \(y = x\) 아래, x가 0부터 2까지의 넓이 \(\int_0^2 x\,dx\)는?
\(\text{밑변} = 2 - 0 = 2,\ \ \text{높이} = 2\)방법 1: x = 2일 때 y = 2
\(\displaystyle \frac{2 \times 2}{2} = \frac{4}{2} = 2\)삼각형 넓이
\(\displaystyle \left(\frac{x^2}{2}\right)' = \frac{2x}{2} = x\)방법 2: 미분해서 x가 되는 식
\(\displaystyle F(2) = \frac{2^2}{2} = \frac{4}{2} = 2\)x 자리에 2 대입
\(\displaystyle F(0) = \frac{0^2}{2} = \frac{0}{2} = 0\)x 자리에 0 대입
\(F(2) - F(0) = 2 - 0 = 2\)방법 1과 같은 답 ✓

도구 1 · 거듭제곱은 같은 수를 여러 번 곱한 것

\(2^3 = 2 \times 2 \times 2\)작은 3은 "3번 곱한다"는 뜻
\(= 4 \times 2\)앞의 \(2 \times 2\)부터 계산
\(= 8\)
\(1^2 = 1 \times 1 = 1\)1은 몇 번 곱해도 1
\(0^3 = 0 \times 0 \times 0 = 0\)0은 몇 번 곱해도 0

규칙 1 · \(x^2\)을 미분하면 \(2x\)

\((x+h)^2 = (x+h)(x+h)\)옆 점의 y
\(= x \cdot x + x \cdot h\): 분배법칙, 앞 괄호의 x를 곱함
\(\quad + h \cdot x + h \cdot h\)앞 괄호의 h를 곱함 (윗줄에 이어짐)
\(= x^2 + 2xh + h^2\)\(xh + hx = 2xh\)
\((x+h)^2 - x^2 = 2xh + h^2\)y의 증가량: \(x^2 - x^2 = 0\)
\(\displaystyle \frac{2xh + h^2}{h} = 2x + h\)x의 증가량 h로 나눔

규칙 2 · \(x^3\)을 미분하면 \(3x^2\)

\((x+h)^3 = (x+h)^2 (x+h)\)3번 곱한 것 = 2번 곱한 것 × 1번 더
\(= (x^2 + 2xh + h^2)(x + h)\)에서 구한 \((x+h)^2\)
\(x^2 \times (x + h) = x^3 + x^2h\): 앞 괄호의 첫째 항
\(2xh \times (x + h) = 2x^2h + 2xh^2\)둘째 항
\(h^2 \times (x + h) = xh^2 + h^3\)셋째 항
\(x^2h + 2x^2h = 3x^2h\)같은 모양끼리 모음
\(2xh^2 + xh^2 = 3xh^2\)같은 모양끼리 모음
\((x+h)^3\)위 결과를 모두 더하면
\(= x^3 + 3x^2h + 3xh^2 + h^3\)같은 모양끼리 모은 결과 사용
\((x+h)^3 - x^3\)y의 증가량
\(= 3x^2h + 3xh^2 + h^3\)\(x^3 - x^3 = 0\)
\(\displaystyle \frac{3x^2h + 3xh^2 + h^3}{h}\)x의 증가량 h로 나눔
