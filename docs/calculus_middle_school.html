중학생도 이해하는 미분과 적분

일차함수의 기울기만 알면 따라올 수 있도록, 풀이를 한 단계씩 풀어 썼어요.

  1. 준비운동: 직선의 기울기
  2. 미분: 곡선의 기울기 구하기
  3. 편미분: 변수가 두 개일 때
  4. 연쇄 법칙: 함수 안의 함수
  5. 적분: 곡선 아래 넓이 구하기
  6. 스스로 풀어보기

0준비운동: 직선의 기울기

중학교 2학년 때 배운 일차함수를 떠올려 봐요. 직선의 기울기는 "x가 1만큼 갈 때 y가 얼마나 올라가는가"예요.

$$\text{기울기} = \frac{y\text{의 증가량}}{x\text{의 증가량}}$$

예를 들어 직선 위의 두 점 \((1, 3)\)과 \((3, 7)\)을 잡으면

$$\text{기울기} = \frac{7 - 3}{3 - 1} = \frac{4}{2} = 2$$

직선은 어디서 재든 기울기가 똑같아요. 그런데 \(y = x^2\) 같은 곡선은 어떨까요? 곡선은 위치마다 기울기가 달라요. 처음엔 완만하다가 점점 가팔라지죠. 이렇게 곡선의 한 점에서의 기울기를 구하는 방법이 바로 미분이에요.

1미분: 곡선의 기울기 구하기

비유: 자동차로 2시간 동안 120km를 갔다면 평균 속력은 시속 60km예요. 하지만 속도계가 보여 주는 건 바로 그 순간의 속력이죠. 미분은 이 "순간의 빠르기"를 구하는 계산이에요.

문제: \(y = x^2\)에서 \(x = 2\)일 때 기울기는?

곡선 위의 점 \((2, 4)\)에서의 기울기를 구해 볼게요. 한 점만으로는 기울기를 계산할 수 없으니, 바로 옆에 점 하나를 더 찍어서 두 점 사이의 기울기를 구하는 방법을 써요.

  1. 옆 점을 멀리 찍어 보기
    \(x = 3\)에 점을 찍으면 \(y = 3^2 = 9\)이니까 점 \((3, 9)\)이에요. $$\text{기울기} = \frac{9 - 4}{3 - 2} = \frac{5}{1} = 5$$
  2. 옆 점을 점점 가까이 가져오기
    \(x = 2.1\)이면 \(y = 2.1^2 = 4.41\)이에요. $$\text{기울기} = \frac{4.41 - 4}{2.1 - 2} = \frac{0.41}{0.1} = 4.1$$ 더 가까이 가져가면 어떻게 될까요? 표로 정리해 봤어요.
    거리 \(h\)옆 점기울기
    1\((3,\ 9)\)5
    0.1\((2.1,\ 4.41)\)4.1
    0.01\((2.01,\ 4.0401)\)4.01
    0.001\((2.001,\ 4.004001)\)4.001
  3. 규칙 발견하기
    거리 \(h\)가 작아질수록 기울기가 4에 점점 가까워져요. 그래서 \(x = 2\)에서의 기울기는 4라고 해요.

모든 x에서 한 번에 구하는 방법

매번 표를 만들 수는 없으니, 문자로 한꺼번에 계산해 볼게요. 점 \(x\)와 옆 점 \(x + h\)를 잡아요.

  1. y 값 각각 구하기
    점 \(x\)에서는 \(x^2\), 옆 점에서는 \((x+h)^2\)이에요.
  2. 곱셈 공식으로 펼치기 (중3에서 배운 \((a+b)^2 = a^2 + 2ab + b^2\)) $$(x+h)^2 = x^2 + 2xh + h^2$$
  3. y의 증가량 구하기 $$\begin{aligned}(x+h)^2 - x^2 &= x^2 + 2xh + h^2 - x^2 \\ &= 2xh + h^2\end{aligned}$$ 아래 그림처럼, 한 변이 \(x\)인 정사각형의 변을 \(h\)만큼 늘리면 늘어난 넓이가 바로 \(2xh + h^2\)이에요.
  4. x의 증가량 \(h\)로 나누기 $$\frac{2xh + h^2}{h} = 2x + h$$
  5. \(h\)를 0에 아주 가깝게 만들기
    \(h\)가 0에 가까워지면 \(2x + h\)는 \(2x\)에 가까워져요. 그래서 \(y = x^2\)의 기울기 공식(도함수)은 $$(x^2)' = 2x$$
  6. x = 2 대입하기 $$2 \times 2 = 4$$ ✓ 표에서 찾은 값 4와 같아요!

자주 쓰는 미분 규칙

같은 방법으로 계산하면 아래 규칙을 얻을 수 있어요. 지수를 앞으로 내리고, 지수는 1 줄인다고 기억하면 돼요.

함수미분한 결과(기울기 공식)기억하는 법
\(5\) (숫자만)\(0\)수평선이라 기울기 0
\(x\)\(1\)직선 \(y=x\)의 기울기
\(x^2\)\(2x\)2를 앞으로, 지수 2→1
\(x^3\)\(3x^2\)3을 앞으로, 지수 3→2
\(2x^3\)\(2 \times 3x^2 = 6x^2\)앞의 숫자는 그대로 곱함

검산: \(x^3\)에서 \(x=1\)과 \(x=1.001\) 사이 기울기를 계산하면 \(\frac{1.003003001 - 1}{0.001} \approx 3.003\)으로, 규칙대로 구한 \(3 \times 1^2 = 3\)에 가까워요.

핵심 정리 · 미분은 곡선의 한 점에서의 기울기를 구하는 것. 옆 점을 아주 가까이 붙여서 두 점 사이 기울기를 구하면 돼요.

2편미분: 변수가 두 개일 때

비유: 산 위에 서 있다고 상상해 봐요. 동쪽으로 걸을 때의 경사와 북쪽으로 걸을 때의 경사는 다를 수 있죠. 편미분은 한 방향으로만 움직인다고 정하고 그 방향의 경사를 구하는 거예요. 나머지 방향은 움직이지 않으니 그냥 숫자처럼 취급해요.

문제: \(f(x, y) = 2x^3 + 3y^3\)의 점 \((1, 2)\)에서 각 방향의 기울기는?

① x 방향 기울기 (y는 움직이지 않음)

  1. y를 숫자로 고정하기
    y는 2에서 움직이지 않으니 \(3y^3 = 3 \times 2^3 = 3 \times 8 = 24\)예요. $$f = 2x^3 + 24$$
  2. x에 대해 미분하기
    \(2x^3\)은 규칙에 따라 \(6x^2\), 숫자 24는 기울기가 0이에요. $$\frac{\partial f}{\partial x} = 6x^2 + 0 = 6x^2$$
  3. x = 1 대입하기 $$6 \times 1^2 = 6$$

② y 방향 기울기 (x는 움직이지 않음)

  1. x를 숫자로 고정하기
    x는 1이니 \(2x^3 = 2 \times 1^3 = 2\)예요. $$f = 2 + 3y^3$$
  2. y에 대해 미분하기
    \(3y^3\)은 \(3 \times 3y^2 = 9y^2\), 숫자 2는 0이에요. $$\frac{\partial f}{\partial y} = 9y^2$$
  3. y = 2 대입하기 $$9 \times 2^2 = 9 \times 4 = 36$$

그래서 점 \((1, 2)\)에서는 x 방향 기울기가 6, y 방향 기울기가 36이에요. y 방향이 훨씬 가파르네요.

기호 \(\partial\)(라운드 또는 델)는 "여러 변수 중 하나에 대해서만 미분했다"는 표시예요.

핵심 정리 · 편미분은 변수 하나만 움직이고 나머지는 숫자로 생각해서 미분하는 것.

3연쇄 법칙: 함수 안의 함수

비유: 톱니바퀴 세 개가 맞물려 있어요. 첫째 바퀴가 1바퀴 돌면 둘째는 2바퀴, 둘째가 1바퀴 돌면 셋째는 12바퀴 돈다면, 첫째가 1바퀴 돌 때 셋째는 \(2 \times 12 = 24\)바퀴 돌겠죠? 이렇게 단계별 빠르기를 곱하는 것이 연쇄 법칙이에요.

문제: \(y = x^2 + 1\), \(z = y^3 - 2\)일 때, \(x = 1\)에서 z의 기울기는?

x가 바뀌면 y가 바뀌고, y가 바뀌면 z가 바뀌어요. 한 줄로 이어진 사슬(연쇄)이죠.

x = 1
× 2→
y = 2
× 12→
z = 6
합치면× 24
  1. 각 값 먼저 구하기 $$\begin{aligned}y &= 1^2 + 1 = 2 \\ z &= 2^3 - 2 = 6\end{aligned}$$
  2. 첫째 톱니: x가 변할 때 y가 변하는 빠르기
    \(y = x^2 + 1\)을 x로 미분하면 \(2x + 0 = 2x\). x = 1을 넣으면 $$\frac{dy}{dx} = 2 \times 1 = 2$$
  3. 둘째 톱니: y가 변할 때 z가 변하는 빠르기
    \(z = y^3 - 2\)를 y로 미분하면 \(3y^2\). y = 2를 넣으면 $$\frac{dz}{dy} = 3 \times 2^2 = 12$$
  4. 두 빠르기를 곱하기 $$\frac{dz}{dx} = \frac{dz}{dy} \times \frac{dy}{dx} = 12 \times 2 = 24$$
  5. 검산하기
    x를 1에서 1.001로 아주 조금 늘려 보면, y = 2.002001, z ≈ 6.024036이 돼요. $$\frac{6.024036 - 6}{0.001} \approx 24.04$$ ✓ 24에 아주 가까워요!

참고로 x 자리에 숫자를 넣지 않고 문자 그대로 계산하면 이렇게 돼요.

$$\frac{dz}{dx} = 3(x^2+1)^2 \times 2x = 6x(x^2+1)^2$$

여기에 \(x = 1\)을 넣어도 \(6 \times 1 \times 2^2 = 24\)예요.

핵심 정리 · 함수가 사슬처럼 이어져 있으면, 각 단계의 기울기를 따로 구해서 곱하면 돼요. 인공지능이 학습할 때도 이 방법을 써요.

4적분: 곡선 아래 넓이 구하기

비유: 미분이 "얼마나 빠르게 변하나"였다면, 적분은 "모두 합치면 얼마인가"예요. 그래프에서는 곡선과 x축 사이의 넓이로 나타나요.

문제 1: \(y = 2x\) 아래, x가 0부터 1까지인 부분의 넓이는?

  1. 모양 확인하기
    \(y = 2x\)는 직선이라 넓이를 구할 부분이 삼각형이에요.
  2. 밑변과 높이 구하기
    밑변은 0부터 1까지라서 1, 높이는 \(x = 1\)일 때 \(y = 2 \times 1 = 2\)예요.
  3. 삼각형 넓이 공식 $$\frac{\text{밑변} \times \text{높이}}{2} = \frac{1 \times 2}{2} = 1$$
$$\int_0^1 2x\,dx = 1$$

기호 \(\int\)(인테그랄)은 S를 길게 늘인 모양이에요. Sum(합)의 S에서 왔어요. \(\int_0^1\)은 "0부터 1까지 더한다"는 뜻이에요.

문제 2: \(y = x^2 + 1\) 아래, x가 0부터 1까지인 부분의 넓이는?

이번엔 곡선이라 삼각형 공식을 쓸 수 없어요. 그래서 얇은 직사각형 여러 개로 잘라서 넓이를 어림해요.

  1. 폭 정하기
    0부터 1까지를 5칸으로 나누면 한 칸의 폭은 \(1 \div 5 = 0.2\)예요.
  2. 높이 정하기
    각 칸의 가운데 지점(0.1, 0.3, 0.5, 0.7, 0.9)에서 \(x^2 + 1\)을 계산해 높이로 써요.
    칸가운데 x높이 \(x^2 + 1\)넓이 = 높이 × 0.2
    10.10.01 + 1 = 1.010.202
    20.30.09 + 1 = 1.090.218
    30.50.25 + 1 = 1.250.250
    40.70.49 + 1 = 1.490.298
    50.90.81 + 1 = 1.810.362
    합계1.330
  3. 더 잘게 자르기
    직사각형을 1,000개로 자르면 1.33333325, 1,000,000개로 자르면 1.3333333333332가 나와요. 잘게 자를수록 1.3333…, 즉 \(\frac{4}{3}\)에 가까워져요.

정확한 값을 한 번에 구하는 방법: 미분을 거꾸로!

적분은 미분의 반대예요. "미분했을 때 \(x^2 + 1\)이 나오는 식"을 찾으면 넓이를 바로 계산할 수 있어요.

  1. 미분해서 \(x^2\)이 되는 식 찾기
    \(x^3\)을 미분하면 \(3x^2\)이에요. 3이 남으니 3으로 나눠 둔 \(\frac{x^3}{3}\)을 미분하면 \(\frac{3x^2}{3} = x^2\)이 돼요.
  2. 미분해서 1이 되는 식 찾기
    \(x\)를 미분하면 1이에요.
  3. 둘을 합치기 (이 식을 미분하면 \(x^2 + 1\)이 돼요) $$F(x) = \frac{x^3}{3} + x$$
  4. 끝값에서 시작값 빼기 $$\begin{aligned}F(1) - F(0) &= \left(\frac{1}{3} + 1\right) - (0 + 0) \\ &= \frac{4}{3}\end{aligned}$$ ✓ 직사각형으로 어림한 1.333…과 같아요!
$$\int_0^1 (x^2 + 1)\,dx = \frac{4}{3} \approx 1.333$$
핵심 정리 · 적분은 곡선 아래 넓이를 구하는 것. 직사각형으로 잘게 나눠 더해도 되고, 미분을 거꾸로 해서 정확히 구할 수도 있어요.

5스스로 풀어보기

풀어 본 뒤 "정답과 풀이 보기"를 눌러 확인하세요.

문제 1. \(y = x^2\)에서 \(x = 3\)일 때 기울기는?

\(x^2\)의 기울기 공식은 \(2x\)예요. \(x = 3\)을 넣으면 \(2 \times 3 = \) 6

문제 2. \(f(x, y) = x^2 + y^2\)의 점 \((3, 4)\)에서 x 방향, y 방향 기울기는?

x 방향: y를 숫자로 보면 \(y^2\)은 기울기 0이니 \(2x\) → \(2 \times 3 = \) 6
y 방향: x를 숫자로 보면 \(x^2\)은 기울기 0이니 \(2y\) → \(2 \times 4 = \) 8

문제 3. \(y = x + 1\), \(z = y^2\)일 때 \(x = 2\)에서 z의 기울기는?

① \(y = 2 + 1 = 3\)
② \(\frac{dy}{dx}\): \(x + 1\)을 미분하면 1
③ \(\frac{dz}{dy}\): \(y^2\)을 미분하면 \(2y = 2 \times 3 = 6\)
④ 곱하기: \(6 \times 1 = \) 6

문제 4. \(\int_0^2 x\,dx\)의 값은? (y = x 아래, 0부터 2까지 넓이)

방법 1 (삼각형): 밑변 2, 높이 2 → \(\frac{2 \times 2}{2} = \) 2
방법 2 (미분 거꾸로): 미분해서 \(x\)가 되는 식은 \(\frac{x^2}{2}\) → \(\frac{2^2}{2} - \frac{0^2}{2} = 2\)

컴퓨터로 확인해 보기

파이썬의 SymPy 라이브러리를 쓰면 위 계산을 컴퓨터로 확인할 수 있어요.

from sympy import symbols, diff, integrate

x = symbols('x')
print(diff(x ** 2, x))                    # 2*x  (미분)
print(integrate(x ** 2 + 1, (x, 0, 1)))   # 4/3  (적분)
